# 📄 HTML Resume Project

This project is a simple personal resume built using only HTML. It represents my profile, skills, education, and contact information in a structured web format as part of my Full Stack Development learning journey.

---

## 📌 Project Description

The HTML Resume includes:

* Personal details
* Career objective
* Educational background
* Skills
* Projects
* Contact information

This project focuses on building a resume layout using basic HTML without any styling (CSS).
